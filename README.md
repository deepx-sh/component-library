# Components Library

A collection of interactive, customizable, and modern UI components built for React projects using **TypeScript**, **Tailwind CSS v4**, and **Motion**.

---

## Features

- **Modern Animations**: Powered by Motion (`motion/react`) for smooth 60fps interactions.
- **Tailwind CSS v4**: Minimal setup using Tailwind v4 styles and animations.
- **Modular Architecture**: Component folder structure built for easy scalability and maintenance.
- **Type-Safe**: Full TypeScript interface support for all component props.
